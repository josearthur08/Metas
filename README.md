# Meta financeira

Um site estático com uma área privada de edição e uma página pública para acompanhar o progresso.

## Como abrir

Abra `editar.html` para criar ou atualizar a meta. O PIN inicial é `2026`.

Depois de salvar, clique em `COPIAR LINK PÚBLICO` e envie o link gerado. Ele abre `Index.html` apenas com a visualização do progresso.

## Uso

1. Entre na área de edição com o PIN.
2. Dê um título para a meta.
3. Informe o valor que deseja atingir e quanto já possui.
4. Clique em `Criar minha meta` ou `Atualizar progresso`.
5. Copie o link público para compartilhar.

O PIN é uma proteção simples no navegador. Para uma proteção real com login, seria necessário um servidor com autenticação.
